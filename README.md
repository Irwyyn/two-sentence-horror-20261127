(`u-suroto-two-sentence-horror-acea9253`). The program `main.ts` writes the
entry text to `/output/entry.txt`.

## The story

Exactly two sentences, 60 characters.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
# out/entry.txt holds the two-sentence horror story
```
